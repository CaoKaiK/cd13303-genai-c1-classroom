| Abbreviation | Full form | Plain-English meaning |
|---|---|---|
| **LLM** | Large Language Model | A model trained on lots of text to understand and generate language. |
| **RAG** | Retrieval-Augmented Generation | A setup where the model first retrieves relevant information, then uses it to answer. |
| **PEFT** | Parameter-Efficient Fine-Tuning | Fine-tuning methods that update only a small part of a model instead of all weights. |
| **LoRA** | Low-Rank Adaptation | A PEFT method that learns small adapter matrices rather than changing the full model. |
| **QLoRA** | Quantized Low-Rank Adaptation | LoRA combined with quantization so large models can be fine-tuned with less memory. |
| **CoT** | Chain-of-Thought | Prompting or reasoning style where the model works through steps to solve a problem. |
| **FM** | Foundation Model | A broad, general-purpose pretrained model that can be adapted to many tasks. |
| **SFT** | Supervised Fine-Tuning | Training a model further on labeled examples to improve task behavior. |
| **RLHF** | Reinforcement Learning from Human Feedback | Improving model behavior using human preferences as feedback. |
| **DPO** | Direct Preference Optimization | A way to train a model from preference data without full RL complexity. |
| **PPO** | Proximal Policy Optimization | A reinforcement learning algorithm often used in alignment/post-training. |
| **MLP** | Multilayer Perceptron | A basic neural network building block made of stacked fully connected layers. |
| **ViT** | Vision Transformer | A transformer-based model architecture for image tasks. |
| **VLM** | Vision-Language Model | A model that works across both images and text. |
| **CLIP** | Contrastive Language-Image Pretraining | A model trained to connect images and text in the same embedding space. |
| **CLAP** | Contrastive Language-Audio Pretraining | A model trained to connect audio and text in the same embedding space. |
| **ASR** | Automatic Speech Recognition | Converting spoken audio into text. |
| **STT** | Speech-to-Text | Another term for converting speech into written text. |
| **TTS** | Text-to-Speech | Converting written text into spoken audio. |
| **OCR** | Optical Character Recognition | Extracting text from images or scanned documents. |
| **GPU** | Graphics Processing Unit | Hardware commonly used to speed up AI training and inference. |
